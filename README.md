#  React Profile Card

A simple and responsive **Profile Card UI** built using **React + Vite**.
This project demonstrates the use of reusable components, JSX, and basic CSS styling.

---

##  Features

* Reusable React components (`Header`, `Footer`)
* Clean and simple UI
* Component-based architecture
* External CSS styling
* Profile card layout design
* Image rendering in React

---

##  Tech Stack

* React
* Vite
* JavaScript (ES6+)
* CSS3

##  Components

###  Header Component

Displays the top section of the profile card (image, name, etc.).

###  Footer Component

Displays social links or contact information like GitHub, Email, etc.

###  App Component

Main component that:

* Connects `Header` and `Footer`
* Builds the full profile card layout

##  How to Run This Project

### 1. Clone the repository

```bash
git clone https://github.com/your-username/react-profile-card.git
```

---

### 2. Go to project folder

```bash
cd react-profile-card
```

---

### 3. Install dependencies

```bash
npm install
```

---

### 4. Start development server

```bash
npm run dev
```
